What it does

Agents build the deck

An MCP server gives Claude Code, Cursor and other agents tools to create a deck, add slides from typed building blocks, and fix what the server rejects.

Present from a URL

Every deck has a link. Open it in a browser and present on a laptop or a phone, with speaker notes and a part tracker that shows where you are in the talk.

Bring the audience in

Coming later: people join with a QR code and answer live polls, word clouds and Q&A from their phones while you drive the deck from yours.

Status

SlideWorks is being built in the open. The first release covers the deck library, the 17 building blocks, sharing and the player. Templates and palettes come next, then the audience features.
